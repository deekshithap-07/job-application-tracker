# Job Application Tracker 💼

A simple and responsive frontend web application that helps users track job applications and their current status.

## 🚀 Features
- Add job applications with company name and role
- Track application status (Applied / Interview / Rejected)
- Edit application status dynamically
- Visual progress bar showing completion
- Persistent data storage using browser localStorage
- Responsive and clean dashboard UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (Vanilla JS)
- localStorage

## 📌 Project Purpose
This project was built to practice frontend fundamentals such as DOM manipulation, state management, and data persistence, while solving a real-world problem faced by students and job seekers.

## 🌐 Live Demo
https://YOUR_USERNAME.github.io/job-application-tracker/

## 📂 How It Works
- Users add job applications through a form
- Application data is stored in localStorage
- Status updates reflect instantly in the dashboard
- Progress bar updates based on completed applications

## 🧠 Key Learnings
- DOM manipulation using JavaScript
- Managing application state without frameworks
- Using localStorage for persistent data
- Building and deploying projects using GitHub Pages
